Place founder, co-founder, and other team photos in this folder.

Update `client/src/data/team.js` with each person's name, role, and photo path:

```js
{ role: 'Founder', name: 'Full name', photo: '/team/founder.jpg' }
```

Add entries to the array for additional people. Photos are cropped into circular portraits.
An empty or unavailable photo displays the avatar placeholder.
